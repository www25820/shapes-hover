# 6 个图形盒子 hover 效果

基于 HTML + CSS 的 6 个图形盒子 hover 演示。背景深色 `#1d1b1a`，容器 flex 横向排布、页面居中，盒子之间留有间距。

## 六个形状

| 序号 | 形状 | 渐变 | 圆角 |
|---|---|---|---|
| c1 | 正圆形 | 橙红 | 50% |
| c2 | 方形 | 青绿 | 小圆角 12px |
| c3 | 方形 | 紫灰 | 大圆角 32px |
| c4 | 正圆形 | 黄橙 | 50% |
| c5 | 方形 | 绿蓝 | 中等圆角 24px |
| c6 | 正圆形 | 浅紫 | 50% |

## hover 交互

- 元素向上移动 10px（`transform: translateY(-10px)`）
- 使用 `transition` 让移动平滑过渡
- 每个图形带向下偏移的 `box-shadow` 阴影，颜色与自身渐变匹配

## 预览

直接用浏览器打开 `index.html` 即可。
